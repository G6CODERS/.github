# Support

## How to get help

| Need | Where |
|---|---|
| Bug in an active repository | Open an issue using the **Bug report** template |
| Feature request | Open an issue using the **Feature request** template |
| Question about usage | Open a discussion or an issue |
| Security vulnerability | **Do not open a public issue** — see [SECURITY.md](SECURITY.md) |
| Client project support | Use the contact channel defined in the client contract |
| Everything else | **g6coders@gmail.com** |

## What to include

- Repository and branch or commit.
- What you expected and what happened.
- Steps to reproduce.
- Logs or screenshots with secrets and personal data removed.

## Response expectations

This is a student-run studio. We triage issues weekly and respond on a best-effort basis. Client contracts take priority over general questions.

## Not supported

- Requests for client code, credentials, or data.
- Free consulting for systems we do not operate.
- Reports about third-party services or dependencies without a concrete impact.
