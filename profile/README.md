## Français

### Qui nous sommes

G6CODERS est un studio logiciel dirigé par des étudiants de Polytech Douala. Nous construisons nos propres produits et livrons des systèmes web pour des organisations.

### Ce que nous faisons

**Produits**

- **PolyExam** — plateforme d'apprentissage pour les étudiants de Polytech : épreuves, corrigés, TD et gestion des abonnements. En développement actif.

**Livraison client**

- Applications web métier, API backend, intégrations de paiement et déploiement cloud.
- Le code client reste privé. Les études de cas publiées sont anonymisées.

## English

### Who we are

G6CODERS is a student-run software studio from Polytech Douala, Cameroon. We build our own products and deliver web systems for organizations.

### What we do

**Products**

- **PolyExam** — a learning platform for Polytech students: past papers, solutions, tutorials, and subscription management. Actively developed.

**Client delivery**

- Business web applications, backend APIs, payment integrations, and cloud deployments.
- Client code stays private. Published case studies are anonymized.

### Status

| Project | Status |

| PolyExam | Active development (private) |
| G6CODERS website | Public source, deployment in progress |
| Client delivery | Private, by referral |

- Bilingual French/English documentation.
